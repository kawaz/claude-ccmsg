たくさんの Claude Code が、ひとつの部屋でおしゃべりする

Claude Code セッション (a1, a2 …) 人 (u1) daemon (番人) room (部屋)

1. むかしは、みんなが1対1で電話していた DR-0001 Context

相手がふえるほど線がからまり、人は同じことを何回も言うはめになった。

2. いまは、番人がいて、部屋がある DR-0001 §2 §3 §5

書けるのは番人だけ。部屋に 1 回はれば、部屋のみんなに本文ごと届く。人 (u1) はどの部屋にも最初からいる。

3. 部屋の記録は、1 冊のノート DR-0001 §4 §6、DR-0003 §2

部屋ごとにノートが 1 冊。番号 (mid) は 1, 2, 3… とつづくので、飛んでいたら「読みに行けばいい」とわかる。

4. つなぎ方は 2 とおり、ことばは 1 つ DR-0001 §7、DR-0003 §1 §3、DR-0004 §1 §2 §3

セッションは同じマシンの中から、人はブラウザから。道はちがうが、番人と話すことばは同じ。ブラウザから来た人はかならず u1 になる。

5. 人は Web 画面で、ぜんぶ見て、話しかける DR-0003 §5、DR-0004 §5 §6、DR-0014 §2.1 §2.2 §2.6

人はどの部屋も読めて、書ける。1 つのセッションだけに言いたいときは、右下の ＋ で「2 人だけの部屋 (1on1)」。相手は自分の画面でふつうに返事する。📣 は「いま声を出したのはこの子」のしるし。

6. 手紙には「返事はどこへ」が書いてある DR-0014 §2.4 §2.5

受け取った側は考えなくていい。書いてあるとおりに返すだけ。ノートには書かず、配るときに相手ごとに書き添える。

7. これから: 番人どうしが手をつなぐ issue multi-host-cluster (計画中、まだ作っていない)

マシンがふえても、番人どうしが手をつなぐ計画。部屋には持ち主の番人が 1 人いて、番号はその番人だけがつける。人の画面は 1 つのままでよい。

持ち主の番人がお休みのあいだ、その部屋は読み書きできない (instance_unreachable)。単位は「マシン」ではなく「instance」(設定フォルダごとに 1 番人)。
