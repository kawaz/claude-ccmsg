# 🔐 のフィルタ画面の各許可依頼に「TL に移動」ボタンを置く

## 概要

🔐 のフィルタ画面の各許可依頼の下に「TL に移動」ボタンを置く。押すとフィルタを外し、その依頼を画面の一番上にして TL に戻る。その依頼が TL に未取得なら、見つかるまで過去分を読み込む。
