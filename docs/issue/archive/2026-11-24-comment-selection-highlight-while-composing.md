# 選択範囲にコメントを書いている間、対象の範囲をハイライトで示す

## 概要

TL の文を範囲選択して 💬 を押すと、その時点で元の範囲選択が消える。コメントを書いている間、どこに付けようとしているのかが画面から分からなくなる。

💬 を押してからコメントを送る (か、やめる) までの間、選択していた範囲をハイライトで示す。

## 背景

kawaz 2026-11-24:

> 選択範囲にコメントつける時、💬押した時点で元の範囲選択が消えるのでその場所はハイライトでわかるようにしておいてほしい。

kawaz 2026-11-24 (上への続き):

> コメントつけた場所に小さい吹き出しが出るのはまぁ良いとして選択テキストはやはりハイライトして欲しい。また、選択場所は部分一致するなら良いが、翻訳文だった場合次見た時は含まないかもしれない。その場合はそのアイテムの uuid からメッセージまでしか特定できないから文中じゃなく右に 💬 出てるべきかな。

## 受け入れ条件

書いている間:

- [x] 範囲選択して 💬 を押した後、入力欄にフォーカスが移っても、選択していた範囲が TL の上でハイライトされている
- [x] やめた時にハイライトが消える
- [x] 範囲選択なしで付けるコメント (メッセージ全体が対象) の見え方は変わらない

送った後 (DR-0062 §2 の探し直しと §3 の表で決まっていて、`comment-quotes.tsx` と `::highlight(ccmsg-comment)` に実装がある。kawaz の画面ではハイライトが見えていないので、実物で確かめる):

- [x] 範囲選択付きのコメントの範囲が、送った後の TL で実際にハイライトされて見える (見えない原因が不具合なら直し、色が薄くて見えないなら見える濃さにする)
  - ハイライトは出ていて、地 (accent の 18%) と吹き出しの地のコントラストの差が小さくて見づらかった (kawaz の見直し 2026-11-24)。地を accent の 50% にし、light / dark の応答・送ったコメント・btw の答えの吹き出しの上で見て分かることをスクリーンショットで確かめた。下線はそのままで、検索のハイライトと重ねても見分けが付く
- [x] いま表示している文の中に選択した文字が見つからない時 (翻訳の表示で選び、次に見た時は原文や別の訳になっている等)、文中には印を出さず、そのメッセージの項目の 💬 でコメントが付いていることが分かる
