# 狭い幅で、返信の吹き出しの足元のツールバーが 2 段に折り返して、時刻の下に 50〜60px の空きが出る

## 現象

幅 390 (スマホ) で、`comment_reply` の応答の吹き出しの下 (時刻の行の下) に、約 50〜60px の空白が出る。幅 1280 では出ない。

## 観測 (2026-11-23、chromium、e2e の fixture の daemon)

吹き出しの足元の行 (`BubbleFooter`) の、hover の時だけ見えるツールバー (`tl-msg-toolbar`) を測った値:

| 幅 | 足元の行の高さ | ツールバーの幅 | ツールバーの高さ |
|---|---|---|---|
| 1280 | 28px | 338px | 28px |
| 390 | 74px | 311px | 51px |

ツールバーには翻訳タブ (203px)、md / source のタブ (93px)、解決の印 (33px) が入っている。幅 390 では吹き出しの幅に収まらず 2 段に折り返し、透明なまま場所を取る (DR-0049 §8 の「透明でも場所は確保する」作り) ので、空白として見える。

## 測り直し (2026-11-23、e2e の fixture の daemon、hover していない状態)

足元の行の高さ / ツールバーの高さ (px)。「全体」はフィルタ無しの TL、「💬」は 💬 のフィルタ。chromium の翻訳のタブは original / ja(browser) / ja(host) の 3 つ、webkit は original / ja(host) の 2 つ。

| engine | 幅 | 吹き出し | 直す前 | 直した後 |
|---|---|---|---|---|
| chromium (mouse) | 390 | ユーザの発言 | 41.6 / 18.2 | 41.6 / 18.2 |
| chromium (mouse) | 390 | 通常の応答 (☰ あり) | 43.6〜66.6 / 20.2〜43.2 | 43.6 / 20.2 |
| chromium (mouse) | 390 | 送ったコメント | 28 / 28 | 28 / 28 |
| chromium (mouse) | 390 | `comment_reply` の応答 (全体・💬) | 74.4 / 51 | 51.4 / 28 |
| chromium (touch) | 390 | 通常の応答 | 66.6 / 43.2 | 43.6 / 20.2 |
| chromium (touch) | 390 | `comment_reply` の応答 | 74.4 / 51 | 51.4 / 28 |
| chromium | 1280 | 全部 | 22.4〜28 | 変わらない |
| webkit | 390 | 通常の応答 / `comment_reply` の応答 | 44.5 / 43.7 | 変わらない |
| webkit | 1280 | 全部 | 22.4 | 変わらない |

- ccmsg のメッセージ (ユーザから) の吹き出しはツールバーを持たず、足元は時刻だけ (22.4) で、どの幅でも変わらない
- 通常の応答の 43.6〜66.6 は、ブラウザ内の翻訳の可用性が届く前 (タブ 2 つ) と後 (タブ 3 つ) の違い。タブ 3 つで ☰ と合わせて 333px になり、吹き出し (311px) の中で 2 段に折り返していた
- 幅 390 で空きが 1 行分 (時刻の下の 20〜28px) 残るのは、ツールバーが時刻の横に収まらず時刻の下の 1 行に移るため。hover で出し入れしても行の高さを動かさない (DR-0049 §8) ための場所

## 原因

- ツールバーが `flex-wrap: wrap` で、吹き出しの幅に収まらない時にタブの組の切れ目で何段にも折り返した
- 見えていない間も場所を取る作り (opacity だけで隠す) なので、折り返した段の数だけ時刻の下に空きが出た

## 対処

- ツールバーを折り返さない 1 行にし、吹き出しの幅に収まらない分は横に送る (`overflow-x: auto`、スクロールバーは出さない)。足元の行は `max-width: 100%` で吹き出しの幅で止める
- TL の幅が 30rem 未満の時 (`@container tl-lines`) は、ツールバーの組の間とタブの左右の余白を詰め (☰ は詰めない)、翻訳のタブ 3 つ・md / source・付随ボタンが横に送らずに収まるようにした
- `packages/webui/e2e/comment-reply.e2e.ts` の「the footers at a phone's width」で、幅 390 の足元の行が時刻の行とツールバーの 1 行を超えないこと、ツールバーが横に隠れていないことを固定した (直す前の app.css で chromium の 2 本が落ちることを確かめた)
