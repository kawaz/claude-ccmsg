# 終了済みのセッションの Status タブを、エラーの文でなく普段の枠で出す

## 概要

終了済みのセッションの Status タブは、「transcript が見つかりません (ccmsg 未接続 + 実行中セッション一覧にも無し)。Session Search から開き直してください」の文だけになり、タブの中身が全部消える。セッションが生きているかに関わらない機能 (同じ cwd で新しいセッションを起動する等) まで使えなくなる。

## 背景

kawaz 2026-11-24:

> 終了済みセッションで、Status がエラー表示されるのをやめてほしい。具体的シチュとして、既存セッションを終了ボタンで終わらせた後、そのまま同じ cwd で新規セッションを起動したいのにステータスがエラー表示だけで全ての機能を拒否する (画面から消し去る) ため、セッションの稼働状態によらない機能までを omit してしまっている。表示できない部分は全て空やゼロ値で埋めるだけで良いはず。そしてその状況を見ればセッションが生きてない事は分かるので余計な状況説明表示とかも出さないで下さい。

## 受け入れ条件

- [ ] 終了ボタンで終わらせた直後のセッションの Status タブが、普段と同じ枠で描かれる (エラーの文だけにならない)
- [ ] セッションが生きていなくても使える機能 (同じ cwd での新規セッションの起動を含む) が、そのまま使える
- [ ] 取れない値は空かゼロで出る
- [ ] 終了済みであることの状況説明の文を出さない

## 解決時の記録先

- Status タブの決まりを持つ DR に、終了済みのセッションでの見え方を今の決まりとして書く
