# 720px 以下の幅で、本文が左に 0.5px はみ出し、右に 0.5px の隙間が出る

## 観測

2026-11-24、e2e の `tl-panels` の webkit の 1 件 (390px で TL のパネルの境目をドラッグすると、木の幅が期待の 95 でなく 94.5 になる) を調べた時の実測。

- 720px 以下の幅では、サイドバーの幅が画面の 85% になる。390px では 331.5px
- `#layout` の横スクロールの位置は整数に丸まる
- その結果、本文 (`main.session-view`) が左に 0.5px はみ出し、右に 0.5px の隙間が出る。セッションの画面 (`.session-panes`) の左端は -0.5px にある
- chromium と webkit の両方で観測した。v0.360.0 でも同じ

## 影響

見た目では分かりにくいが、位置を測る処理が半端な値を受け取る。上の e2e は、WebKit が渡すポインタの位置 (整数) から、左端の -0.5px を引いて 94.5 になっていた (テストの側は、整数の位置へ動かして木の右端がそこに来ることを確かめる形に直した)。

## 直し方の方向 (未検証)

サイドバーの幅を、割合のままでなく整数の px に丸める (CSS の `round()` 等)。丸めた時に、広い幅や他の幅の指定とぶつからないかは確かめていない。
