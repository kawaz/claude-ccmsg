# .svg のビューアの「実行」の失敗の文が、別のファイルに移っても残る

`.svg` のファイルのビューアで「実行」を押して grant が断られる (または答えが待つ時間のうちに来ない) と、ヘッダの区画 (`FileViewer.tsx` の `SvgFileTabs`) が理由の文を出す。この文は、別のファイルに移っても消えない。

svg の実行 (DR-0067) を実装した worker の報告で分かった。実物での再現は未確認。

## 直す形

描画 / ソースの選択と同じに、ファイル (`sid` と `path`) が変わった時点で捨てる (`useResettableState`)。直す前に落ちる試験を先に書く。
