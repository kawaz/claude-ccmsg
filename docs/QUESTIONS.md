「プロセスは終了するがセッションリストには残す」分類。統括案は「前回稼働中エントリの昇格」:
`last-live-sessions.json` のエントリに `stopped_at` を足し、Busy の Status に一時停止ボタン

弱点: 前回稼働中の行を後から Stopped に昇格させる導線が無い。
