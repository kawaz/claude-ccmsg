## 裁定待ち

### AGY-Q1 agy の tool の安全の境

全許可で動く agy を起こす tool を、誰のどの入力で呼べるようにするか。今の ccmsg の tool はどれも permission の判定を通らない。筋ごとの表は [DR-0066](./decisions/DR-0066-agy-conversation-tool.md) §11、選択肢は同 Q3。

- [ ] a: この tool だけ permission の判定を通す (推し。作れるかは Claude Code の側の実測が要る。作れなければ b)
- [ ] b: 判定を通さず、設定で口を開けた環境でだけ使える (開けた環境では、agy の応答に混ざった他人の文・他のセッションの封筒・subagent などの筋は塞がらない)
- [ ] c: コンテナで囲えるようになるまで出さない

### AGY-Q2 同じ会話の agy が 2 重に起きた時、どちらを止めるか

「若い方」がどちらを指すかの確認。[DR-0066](./decisions/DR-0066-agy-conversation-tool.md) Q1。

- [ ] a: 後から起きた方を止める (推し。まだ依頼を書いていないので失うものが無い)
- [ ] b: 先に起きた方を止める (走っていたターンが中断になる)

### AGY-Q3 本体への agy の応答の届け方

今の決定は append (送り主の印は `agyid:<ID>`)。append は枠なしでユーザの発言として入り、止まっている本体は起きず、読まれたかの見届けが要る。[DR-0066](./decisions/DR-0066-agy-conversation-tool.md) §7 と再考の提案 R2。

- [ ] a: 封筒 1 本にする (推し。権限を与えない枠が付き、止まっている本体も起き、見届けが要らない。印は `agyid:<ID>` のまま)
- [ ] b: 決定どおり append (止まっている時だけ封筒)
