> 運用規約 (ゼロコンテキスト読者向け、新セッションはまずここを読む):
> - ユーザ裁定が必要な確認事項をラベルで常時集約する。
> - ラベルはバッチやセッション毎に一意な短プレフィクス (XX-Q1 形式、Qn 単独の使い回し禁止、長期一意性不要)

> - 裁定済み・過去参照に👺を付けない (ユーザはTLで 👺 正規表現でハイライト/アラームしており誤陽性が有害)
> - チャット提示と同一ターンで本ファイルに記録 + path 指定 commit する

> - 確認待ちの削除条件は 2 つ: ユーザが確認 OK を返した / 後続リリースで当該実装が上書きされ確認対象でなくなった
> - 本ファイルが空になったら `docs/QUESTIONS.template.md` をコピーして書き始める (規約の正本はテンプレ側、本体に規約を書き写して二重管理にしない)
> - ユーザへの裁定や確認依頼はチャットで長文説明せず、当該 Q をファイルに簡潔記載して、👺ラベル 提示形式で依頼する。
> - ユーザに提示する参照パスはリポ内相対。リポ外ファイルはフルパス表記
> - ルール正本は claude-rules-personal の `questions-md-registry` 参照。
