## 裁定待ち

room 廃止 ([DR-0036](decisions/DR-0036-retire-rooms-for-p2p.md)) の細部。いずれも a が統括推し。

### RM-Q1 届かなかったセッション間メッセージの扱い

- [ ] a: 理由を送り主に返すだけで、daemon は預からない (送り主の agent が再送か断念を決める。v1 だけの永続状態を増やさない)
- [ ] b: v2 の inbox (永続・再提示) を v1 に移す

### RM-Q2 セッションから人への経路

- [ ] a: 新しく作らない (人への返事は TL、自発的な知らせは PushNotification で足りる)
- [ ] b: v2 と同じく `ccmsg reply <mid>` の `--to` 無しを人宛の通知にし、webui に通知一覧を作る

### RM-Q3 全セッションへの一斉送信 (broadcast の代わり)

- [ ] a: 持たない (必要なら `ccmsg peers` の結果に順に送る)
- [ ] b: 一斉送信の op を作る

### RM-Q4 `ccmsg say` の記録と未読

- [ ] a: notify の流れに載せ、未読は daemon のメモリだけで持つ (再起動で未読が消えるのは許容)
- [ ] b: say 専用の小さな記録ファイルを持つ

### RM-Q5 既存の room データ (384 ファイル、約 6MB)

- [ ] a: ファイルは消さずに残し、webui の閲覧 UI とコードは削る
- [ ] b: 読み取り専用の最小の閲覧 (一覧と本文) を残す

### RM-Q6 room 一覧に代わる横断ビュー

- [ ] a: 作らない (やり取りは各セッションの TL で見る)
- [ ] b: v2 webui の inbox / 通知一覧に相当するビューを作る
