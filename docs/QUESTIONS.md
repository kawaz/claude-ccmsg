## 裁定待ち

### AGY-Q7 起こす知らせ「何もせず次の指示を待て」が、agy の応答の後や作業の途中に読まれる場合

決まったこと: 起こす知らせの中身は「何もせず次の指示を待て」(送り主 `ccmsg:wakeup`)、append の後に止まっているかによらず毎回送る ([DR-0066](./decisions/DR-0066-agy-conversation-tool.md) K14、Q18 の c)。この 2 つが合わさると、知らせが次の 2 つの場面で読まれる。

- 止まっている本体: agy の応答を append した後に知らせが読まれるので、足された応答まで「何もしない」対象と読むおそれがある
- 走っている相手: 作業の途中で知らせを読み、今の作業を止めるおそれがある

- [ ] a: 文を変える (推し。例「この知らせ自体への対応は不要。直前に足された文を読んで続けよ」のように、知らせへの反応だけを止める言い方にする。文面は kawaz が決める)
- [ ] b: 文はそのままで、走っている相手には送らない (Q18 の c から外れ、足した時に止まっていたかの判定が戻る。止まっている本体の件は残る)
- [ ] c: このまま進め、実環境で起きたら直す
